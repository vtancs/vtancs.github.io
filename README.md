# vtancs.github.io

Personal portfolio site for Victor Tan — ML Researcher, based in Singapore.

**Live**: [vtancs.github.io](https://vtancs.github.io/)

## Status

Initial base version. Plain HTML/CSS/JS, no build step required.

## Structure

```
index.html   # page markup (hero, about, skills, projects, contact)
style.css    # dark theme styling
script.js    # small helpers (footer year)
me.png       # profile photo
```

## Editing

Just edit `index.html` / `style.css` directly and push to `main` — GitHub Pages
rebuilds automatically.
