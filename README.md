# Victor's Portfolio

A modern, responsive portfolio website showcasing my work as an ML Researcher.

**Live**: [vtancs.github.io](https://vtancs.github.io/)

---

## Features

- Modern dark theme
- Fully responsive design
- Project showcase pulled from [github.com/vtancs](https://github.com/vtancs)
- Single-file, no-build static site

---

## Tech Stack

- Vanilla JavaScript, HTML5, CSS3
- GitHub Pages for deployment

---

## Getting Started

```bash
# Clone
git clone https://github.com/vtancs/vtancs.github.io.git
cd vtancs.github.io

# Serve locally (any static server works)
python -m http.server 8080
```

Then open `http://localhost:8080` in your browser.

---

## Project Structure

```
index.html   # page markup (hero, about, skills, projects, contact)
style.css    # dark theme styling
script.js    # small helpers (footer year)
me.png       # profile photo
```
